# Security Policy

## Supported Versions

Security fixes target the latest released version of GentisAI.

## Reporting A Vulnerability

Please report vulnerabilities privately by opening a GitHub security advisory or contacting the maintainers listed in `pyproject.toml`.

Include:

- Affected version or commit
- Reproduction steps
- Impact
- Suggested mitigation, if known

Do not publish exploit details until a fix is available.
